# تعدين ADVC في المتصفح — تشغيل اختياري

واجهة عربية بسيطة لاستخدام مكتبة [`cpu-web-miner`](https://github.com/MarcoCiaramella/cpu-web-miner) لتعدين ADVC عبر المتصفح.

## سلوك الموافقة والخصوصية

- لا يبدأ التعدين عند فتح الصفحة، ولا يُستأنف تلقائيًا بين الزيارات.
- يجب تحديد خانة الموافقة ثم الضغط صراحةً على «بدء التعدين الآن».
- تظهر الصفحة أثر استهلاك المعالج والطاقة، وخادم المجمع، والوسيط ورسومه المذكورة في README الأصلي (1% من الأسهم).
- يمكن إيقاف التعدين من الزر أو بإغلاق الصفحة. الحد الابتدائي خيط واحد؛ ويمكن للزائر زيادة العدد يدويًا حتى عدد خيوط جهازه.
- عنوان المحفظة المعبأ مسبقًا هو العنوان الذي قدمه صاحب المشروع. يُرسل إلى خدمة الوسيط عند بدء التعدين. لا تحفظ الصفحة موافقة المستخدم أو مدخلاته محليًا.

**لا تستخدم التعدين المخفي أو التلقائي دون إذن واضح من مستخدم الجهاز.** هذه النسخة لا تنفذ ذلك؛ التشغيل لا يتم إلا بعد موافقة لحظية وزر البدء.

## الإعداد

- الخوارزمية: `yespowerADVC`
- الخادم والمنفذ: `eu.rplant.xyz:17149`
- TLS: مفعّل
- كلمة مرور العامل: `x`
- مكتبة التعدين تتصل بخادم Socket.IO الوسيط `websocket-stratum-server.com` وفق مصدر المكتبة المنشور، وليس مباشرةً بالمجمع.

تُحمّل وحدة المكتبة من esm.sh **بعد** تفاعل المستخدم مع زر البدء. يتطلب ذلك اتصال إنترنت وسياسة CSP تسمح بـ `https://esm.sh` وبالاتصالات اللازمة لخدمة التعدين. تحقق من المكتبة ومصادرها وسياسة الخصوصية قبل نشر الموقع للآخرين.

## التشغيل محليًا

شغّل خادم ملفات ثابتًا من مجلد المشروع، مثلًا:

```bash
python3 -m http.server 8000
```

ثم افتح `http://localhost:8000`. لا تفتح الملف عبر `file://` لأن وحدات JavaScript والاتصالات الآمنة تتطلب سياق HTTP/HTTPS مناسبًا. استخدم HTTPS عند النشر العام.
